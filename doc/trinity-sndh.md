# Trinity — SNDH-плеер в RP-AY (идея, 2026-10-18)

Музыка Atari ST играется прямо в RP-AY: эмулируем 68000 и MFP, записи в YM уходят в **живой AY** — SID, бузер,
дижидрамы делает код музыканта, мимо FX-регистров. Концепт — `doc/trinity-concept.md`, связь RP — `doc/zx-trinity.md`.

## Что нашёл пользователь

- **SndhArchivePlayer v1.21** (Leonard / Oxygene = Arnaud Carré) — у пользователя `d:\Data\Speccy\Atari\SndhArchivePlayer`
  (только exe и README). Исходники: github.com/arnaud-carre/sndh-player.
- Движок — библиотека **AtariAudio**: github.com/arnaud-carre/AtariAudio, лицензия **MIT** (нам подходит, можно брать в
  прошивку). Автор: без зависимостей, без float, «собирается на встраиваемых» (его слова, портов на МК нет).

## Что внутри AtariAudio (`src/`)

| Файл | Что |
|---|---|
| `AtariMachine.cpp/.h` | машина: RAM, порты, 68000 (Musashi в `external/`), шаг MFP, вызовы плеера |
| `Mk68901.cpp` | MFP (таймеры A..D) |
| `ym2149c.cpp`, `ym2149_tables.h` | эмуляция YM2149 (у нас не нужна — пишем в живой AY) |
| `SteDac.cpp`, `Blitter.cpp` | STE DMA-звук, блиттер (на AY не играет) |
| `SndhRenderer.cpp`, `YmRenderer.cpp` | форматы `.sndh` (код 68000) и `.ym` (дамп регистров) |
| `timedb.cpp` | длительности песен |

API: `Create(файл, размер, частота, такт YM)`, `InitSubSong(n)`, `AudioRender(буфер, сэмплов)` — 16 бит моно.

## Куда врезаться

- Запись в YM — одно место, `AtariMachine.cpp`: адреса `#FF8800..#FF88FF` -> `m_ym2149.WritePort(addr & #FE, val)`
  (0 — номер регистра, 2 — данные). Подменяем на запись в AY (тень + шина чипа) — эмуляцию YM выкидываем.
- Время: `ComputeNextSample()` на каждый выходной сэмпл тикает MFP (`m_mfp.Tick(t)`); сработал таймер — 68000 крутит
  его обработчик до RTE. Раз в кадр 50 Гц — `PlayerTick()` (sound list + плеер музыки). Звук считать не нужно:
  крутим тот же цикл с «частотой сэмпла» ~50 кГц — точность записей таймеров ~20 мкс, для SID хватает.

## Что учесть

- **Память:** машина — 2 МБ RAM (`RAM_SIZE`, с v0.40) — в PSRAM (8 МБ) влезает с запасом; во внутренние 520 КБ SRAM
  не влезает. Вопрос только скорости: PSRAM через кэш XIP (16 КБ) медленнее SRAM — замерить; если мало, держать
  RAM машины в SRAM урезанной (большинству SNDH хватает меньше — проверить). Модуль RP-AY — с PSRAM.
- **Такт — НЕ ЗАБЫТЬ (пользователь, 2026-10-18):** YM у ST — 2 МГц, AY Евы — 1.75. Чипы карты — YM2203: SSG звучит как AY
  на φM / 2 (TurboSound FM: φM 3.5 МГц = AY 1.75). Для SNDH нужен φM **4 МГц** — значит, на карте φM чипов даёт RP
  (или переключаемый генератор), а не шина. Иначе — пересчёт периодов (×0.875, округление — лёгкая расстройка).
- **AY или YM:** у YM2149 огибающая 32 шага, у AY 16; громкости чуть другие. Ножки совместимы — кто хочет точно,
  ставит YM2149.
- **Не играют:** тунцы со STE DMA-звуком и блиттером (цифра, не YM).
- **`.ym`-файлы** (дамп регистров 50 Гц) — ещё проще: 68000 не нужен; эффекты YM5 / YM6 (SID, Sync-бузер, дижидрамы)
  записаны в файле параметрами — ложатся на наши таймерные эффекты почти напрямую.
- **Откуда файл:** с SD карты (RP-GS -> UART -> RP-AY) или с диска Евы (поток `#C1`, пакет «залить / играть / стоп»).
