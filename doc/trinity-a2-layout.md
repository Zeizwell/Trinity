# Плата рев A2 — кто куда смотрит (без перехлёстов)

Расстановка — конфиг п.74 (`KiCad/revA2`). Здесь: какой стороной каждая деталь к кому, чтобы шины шли прямо.
Сторона по картинке платы: лево — задняя планка, низ — ламели шины. Координаты — из `trinity_a2.kicad_pcb` (2026-11-15).

## Детали

| Деталь | Где | Куда смотрит |
|---|---|---|
| RP-GS (U2) | низ слева | USB-C — влево в планку. Ножки — ниже, «RP-GS». |
| microSD (J3) | левый край, над RP-GS | прорезь — в планку; ножки — к верхней стороне RP-GS (GP44-47 у USB-конца). |
| Гнездо линии (J2) | левый край, верх | носик — в планку. |
| ЦАП PCM5102A (U6) | над правым концом RP-GS | I2S — вниз к GP28-31 RP-GS, выход — к гнезду. |
| Сумматор NJM4580 (U7), narrow 74HC4053 (U9), TPA6120A2 (U8) | между гнездом / SD и ключами AY | входы — к выходам AY, выход — к гнезду. J4 (HD Audio) — где удобно (выход низкоомный). |
| AY ×2 (U4, U5) | верх посередине, горизонтально, друг под другом | ключ (выходы A 4, B 3, C 38, питание) — влево к аналогу. Шина (ножки 22-37) — верхний ряд, вправо к RP-AY. |
| RP-AY (U3) | правый край, верх | USB-C — вправо. Ножки — ниже, «RP-AY». |
| CPLD (U1) | прямо над правым концом ламелей | см. «CPLD». |
| Питание +5 / GND (J5) | правый край, под RP-AY | — |

## RP-GS (U2): стороны модуля

| Сторона | Ножки (от USB) | Куда |
|---|---|---|
| верх (Y 101) | 5V, GND, 3V3, EN, GND, GP47 … GP28 | SD, ЦАП, связь с RP-AY (правый конец — через коридор) |
| низ (Y 124.5, до края 2.5 мм) | GP0 … GP18, GP19, GP21 … GP25 | шина к CPLD: под модулем вправо, в коридор под U5 |
| торец (X 92) | G, RUN, G, GP27, GP26, GP20 | к CPLD / RP-AY (верх коридора) |

Ножки:
- **Шина к CPLD — GP2-18 подряд (17), одно чтение:** GP2-9 GS_D0-7, GP10-15 GS_C0-5, GP16 GS_WR, GP17 GS_RD, GP18 GS_RDY.
  GP19 (PSRAM модуля) и GP24 (VBUS) — не трогать.
- GP21 CPLD_CLK (GPOUT0).
- JTAG CPLD (шьёт RP-GS): GP22 TCK, GP23 TMS, GP25 TDI, GP1 TDO.
- Связь с RP-AY (п.68): GP28 BCK / GP29 LRCK (те же, что на ЦАП), GP32 AY_DATA (от RP-AY), GP33 AY_MIX, GP26 TX / GP27 RX
  (UART1, доп. функция RP2350), GP20 -> RUN RP-AY, запас GP34, GP35.
- ЦАП: GP28 BCK, GP29 LRCK, GP30 DIN, GP31 XSMT.
- microSD (SPI1): GP44 MISO, GP45 CS, GP46 SCK, GP47 MOSI.
- GP43 — детект microSD. Свободны: GP0, GP36-42 — гребёнка J6.

Порядок в коридоре (сверху вниз): верхние ножки GP28-35 (связь), торец GP27 / 26 / 20, низ справа налево GP25 … GP21, GP18 … GP2,
GP1. В левую сторону CPLD шина входит в том же порядке (GP18 — верхняя ножка).

## RP-AY (U3): стороны модуля

| Сторона | Ножки | Куда |
|---|---|---|
| низ (Y 97.8) | GP28 … GP47, потом GND, EN, 3V3, GND, 5V у USB | левая часть (GP28-33) - связь с RP-GS, правая (GP34-47) - вниз-влево к CPLD |
| верх (Y 74.3, до края 3.7 мм — опустить RP-AY на ~5 мм) | GP25 … GP0 (GP0 у USB) | к AY: вверх, влево вдоль верха |
| торец (X 194.5) | GP20, GP26, GP27, G, RUN, G | к AY (GP20) и в коридор (GP26, 27, RUN) |

Ножки:
- **Шина к CPLD — GP34-47 подряд (14), одно чтение:** GP34-41 AY_D0-7, GP42 AY_C0, GP43 AY_C1, GP44 AY_WR, GP45 AY_RD,
  GP46 AY_RDY, GP47 AY_RST. Правая часть стороны: линии связи (левее) её не пересекают.
- Связь с RP-GS (левая часть низа и торец): GP28 BCK, GP29 LRCK, GP30 MIX_DATA, GP31 MIX_ON, GP32 TX / GP33 RX (UART0),
  запас GP26, GP27 (LINK1 / 2), RUN — от GP20 RP-GS.
- AY: GP11-18 PSG_D0-7 (общая шина двух AY, подряд), GP20-23 BC1 / BDIR AY1, BC1 / BDIR AY2 (подряд), GP25 PSG_CLK
  (GPOUT3), GP10 ~PSG_RST, GP9 NARROW (74HCT4053). Подтяжки 10к вниз на стробы, сброс и NARROW: пока RP грузится,
  AY молчат, narrow выключен. AY не читаем никогда (BDIR 0 / BC1 1 не выставлять): 5 В с AY на RP не попадает.
- Свободны: GP0-8 — гребёнка J7.

## CPLD (EPM3128ATC100)

QFP-100: 1-25 лево (сверху вниз), 26-50 низ (слева направо), 51-75 право (снизу вверх), 76-100 верх (справа налево).
Порядок ножек в каждой группе — такой, чтобы пучок шёл без перехлёстов (порядок ламелей / ножек RP).

| Группа | Ножки CPLD | Откуда |
|---|---|---|
| RP-GS, 17 | 97 RDY, 98 RD, 99 WR, 100 C5, 1 C4, 2 C3, 5 C2, 6 C1, 7 C0, 8-10, 12-14, 16, 17 D7…D0 | коридор под U5, вверх между U5 и CPLD |
| ZX, 36 | лево 19-25, низ 27-50, право 52-64 — по порядку ламелей слева направо | полоса под коридором RP-GS |
| RP-AY, 14 | верх 84, 83, 81, 80, 79, 77, 76 — AY_D0-6; право 75 D7, 72 C0, 71 C1, 70 WR, 69 RD, 68 RDY, 67 RST | сверху справа, за угол |
| такт | 90 (GCLK2) | RP-GS GP21, поверху |
| DIP-4 (п.47) | 85, 87, 88, 89 | DIP — над CPLD, под линиями связи |
| JTAG (свои ножки) | TDI 4, TMS 15 (лево), TCK 62, TDO 73 (право) | от RP-GS; 4 / 15 / 62 / 73 внутри чужих пучков — с переходными |
| запас | 92, 93, 94, 96 | — |

Зазор между U5 и CPLD — коридор RP-GS (17) + ZX лево (7) идут вверх: нужно ~10 мм (сейчас ~6), поправить при разводке.
Ножки CPLD назначаются свободно (Quartus), сверить фит после назначения.

## История — устарело

  На рев A2 RP-GS слева от CPLD — распиновка новая.
